### 1.2 Triển khai Word Embeddings

#### **Bước 1: Tạo WordEmbedder**
**File**: `src/representations/word_embedder.py`

**Mục đích**: Tạo interface thống nhất để load và sử dụng pretrained word embeddings từ gensim.

**Chức năng chính**:
- Load pretrained models từ gensim downloader
- Lấy vector embedding của một từ
- Kiểm tra từ có trong vocabulary không
- Trả về kích thước vector

**Pretrained models hỗ trợ**:
- `glove-wiki-gigaword-50` (50D, 400K vocab) -- đang sử dụng
- `glove-wiki-gigaword-100` (100D, 400K vocab)
- `word2vec-google-news-300` (300D, 3M vocab)

#### **Bước 2: Tạo DocumentEmbedder**
**File**: `src/representations/document_embedder.py`

**Mục đích**: Chuyển đổi document (câu/đoạn văn) thành vector.

**Phương pháp**:
- Tokenize document thành các từ
- Lấy word vector cho mỗi từ
- Aggregation bằng mean pooling (trung bình các word vectors)
- Xử lý OOV (Out-of-Vocabulary): Trả về zero vector nếu không có từ nào trong vocab

### 1.3 Training Word2Vec

#### **Bước 3: Gensim Local Training**
**File**: `test/lab4/run_word2vec_tests.py`

**Quy trình**:
1. Load C4 dataset (30,000 documents từ file JSON Lines)
2. Preprocessing: Lowercase, chỉ giữ lại ký tự alphabet
3. Tokenization: Split thành words
4. Train Word2Vec với gensim

**Hyperparameters**:
- `vector_size=100`: Dimension của word vectors
- `min_count=5`: Loại bỏ từ xuất hiện < 5 lần
- `workers=4`: Số threads parallel
- `epochs=3`: Số lần train qua dataset
- `window=5`: Context window size
- Algorithm: CBOW (Continuous Bag of Words)

**Output**:
- Vocab size: ~41,000 từ
- Train time: ~19-20 giây
- Vector cho từ "computer" (100D)
- Top-5 similar words với similarity scores

#### **Bước 4: PySpark Distributed Training**
**File**: `src/spark/lab4_task4_pyspark.py`

**Quy trình**:
1. Khởi tạo SparkSession với local master
2. Load JSON data vào DataFrame
3. Preprocessing pipeline:
   - Lowercase text
   - Remove non-alphanumeric characters
   - Split thành tokens
4. Train Word2Vec với MLlib
5. Find synonyms và extract vectors

**Ưu điểm PySpark**:
- Xử lý distributed trên large datasets
- Tự động parallelize training
- Tích hợp với Spark ML pipeline
- Scalable cho big data

**Lưu ý Windows**:
- Cần Java runtime (JDK 8 hoặc 11)
- Sử dụng `--no-save` flag để tránh lỗi winutils.exe khi save model
- WARN messages về Hadoop là bình thường, không ảnh hưởng training

### 2.1 Phân tích Model Pretrained (GloVe)

#### **Độ tương đồng và từ đồng nghĩa**

Từ kết quả test với từ "computer" trên model GloVe-50:

```
[TOP-5 SIMILAR TO 'computer']
computers: 0.9165
software: 0.8815
technology: 0.8526

internet: 0.8060
```

**Nhận xét**:
- Top-5 đều có semantic relationship mạnh với "computer" (scores 0.80-0.91)
- Phân cấp rõ ràng: morphological variant (computers) → functional relation (software) → domain terms (electronic, internet)
- Model pretrained bắt được nhiều relationships hơn vì train trên large corpus

### 2.2 Phân tích biểu đồ trực quan hóa

#### **Pretrained Model (`embedding_visualization.png`)**

- Domain clusters: computer, software, technology gần nhau
- Semantic fields: country, government, state tạo nhóm politics
- Function words: articles (the, a, an) rất gần nhau
- PCA 2D (28% variance) và 3D (38% variance) - 3D structure rõ hơn

#### **Trained Model (`embedding_visualization_trained.png`)**

**Category Separation (PCA 2D - 38% variance, 3D - 49% variance)**:
- **Technology** (đỏ): Cluster tập trung nhất, similarity cao
- **Science** (xanh): Overlap với Business (research - company)
- **Business** (xanh lá): Cluster rõ, separate với Technology
- **Politics** (cam): Đặc trưng riêng, ít overlap
- **Common words** (xám): Phân tán vì co-occur với mọi domain

**Giải thích**: Clusters hình thành do các từ có similar contexts -> similar vectors.

### 2.3 So sánh Pretrained vs Trained Model

1. **Vocabulary**: Pretrained có morphology tốt (bắt được mối quan hệ các biến thể của từ vd như là thì quá khứ, số nhiều, so sánh,.. cùng root -> vector embedding gần nhau), Trained có phù hợp hơn với tài liệu có thuật ngữ chuyên ngành (domain-specific terms)
2. **Granularity**: Pretrained abstract (technology), Trained concrete (desktop, server)
3. **Performance**: Pretrained 0.084s query, Trained 0.013s (nhanh hơn gấp 6 lần do vocab nhỏ hơn)
4. **Quality**: Pretrained scores 0.80-0.91 (clearer peaks), Trained 0.79-0.82 (more uniform)

### 3.4 Troubleshooting

**Lỗi: ModuleNotFoundError**
```bash
pip install gensim pyspark scikit-learn matplotlib numpy
```

**Lỗi: Java not found (PySpark)**
- Cài đặt JDK 8 hoặc 11
- Set JAVA_HOME environment variable

**Lỗi: winutils.exe (Windows + PySpark)**
- Sử dụng flag `--no-save` khi chạy PySpark
- Hoặc cài đặt Hadoop winutils: https://github.com/cdarlint/winutils

**Lỗi: Out of memory**
- Giảm số documents trong C4 dataset
- Giảm `vector_size` hoặc tăng `min_count`

**Download pretrained model chậm**
- Lần đầu load GloVe sẽ download ~65MB
- Lần sau sẽ dùng cached model (~/.gensim-data/)
