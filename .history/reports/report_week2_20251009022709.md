- **Data source**: `data/c4-train.00000-of-01024-30K.json.gz`
- **Document limit**: 2,000 records
- **HashingTF features**: 20,000 dimensions
- **Processing time**: 121.37 seconds total

### 1.2 Thiết kế pipeline NLP
Pipeline được thiết kế với 4 giai đoạn chính:

1. **RegexTokenizer**: Text tokenization into individual words
2. **StopWordsRemover**: Remove common low-information words  
3. **HashingTF**: Transform text into term frequency vectors
4. **IDF**: Apply inverse document frequency weighting

## 7. Khó khăn và giải pháp

### 7.1 Hash Collision
- **Vấn đề**: Vocabulary size (39,585) > feature space (20,000)
- **Impact**: Hash collision rate ~49.5%
- **Giải pháp**: Trade-off giữa memory và accuracy, có thể tăng numFeatures

### 7.2 Vector Search Performance
- **Challenge**: Search qua large document collection
- **Solution**: Limit search scope (100 documents) để cân bằng speed/accuracy

### 7.3 Môi trường Windows
- **Issue**: Hadoop/Parquet compatibility warnings
- **Resolution**: Sử dụng text-based output thay vì Parquet
