### 1.2 Triển khai Word Embeddings

#### **Bước 1: Tạo WordEmbedder wrapper (src/representations/word_embedder.py)**

Mục đích: Tạo interface thống nhất để load và sử dụng pretrained word embeddings từ gensim.

```python
import gensim.downloader as api

class WordEmbedder:
    def __init__(self, model_name: str):
        """Load pretrained model từ gensim (VD: glove-wiki-gigaword-50)"""
        self.model = api.load(model_name)
        self.model_name = model_name
    
    def get_vector(self, word: str):
        """Lấy vector embedding của một từ"""
        return self.model[word]
    
    def __contains__(self, word: str):
        """Kiểm tra từ có trong vocabulary không"""
        return word in self.model
    
    def vector_size(self):
        """Trả về kích thước vector"""
        return self.model.vector_size
```

**Các pretrained models hỗ trợ:**
- `glove-wiki-gigaword-50` (50D, 400K vocab)
- `glove-wiki-gigaword-100` (100D, 400K vocab)
- `word2vec-google-news-300` (300D, 3M vocab)

#### **Bước 2: Tạo DocumentEmbedder (src/representations/document_embedder.py)**

Mục đích: Chuyển đổi document (câu/đoạn văn) thành vector bằng cách lấy trung bình các word vectors.

```python
import numpy as np
from src.preprocessing.regex_tokenizer import RegexTokenizer

class DocumentEmbedder:
    def __init__(self, embedder, tokenizer=None):
        self.embedder = embedder
        self.tokenizer = tokenizer or RegexTokenizer()
    
    def embed(self, document: str):
        """Embed một document thành vector"""
        tokens = self.tokenizer.tokenize(document)
        vectors = []
        
        for token in tokens:
            if token in self.embedder:
                vectors.append(self.embedder.get_vector(token))
        
        if not vectors:
            return np.zeros(self.embedder.vector_size())
        
        return np.mean(vectors, axis=0)
```

**Phương pháp aggregation:**
- Mean pooling: Lấy trung bình các word vectors
- Xử lý OOV (Out-of-Vocabulary): Trả về zero vector nếu không có từ nào trong vocab

### 1.3 Training Word2Vec

#### **Bước 3: Gensim Local Training (test/lab4/run_word2vec_tests.py)**

Train Word2Vec trên C4 dataset sử dụng gensim:

```python
from gensim.models import Word2Vec
import json

# Load C4 dataset (30K documents)
texts = []
with open('data/c4-train.00000-of-01024-30K.json', 'r') as f:
    for line in f:
        texts.append(json.loads(line)['text'])

# Tokenize
tokenized = [[w for w in t.lower().split() if w.isalpha()] for t in texts]

# Train Word2Vec
model = Word2Vec(
    tokenized,
    vector_size=100,    # Kích thước vector
    min_count=5,        # Loại bỏ từ xuất hiện < 5 lần
    workers=4,          # Số threads
    epochs=3            # Số epochs training
)
```

**Hyperparameters:**
- `vector_size=100`: Dimension của word vectors
- `min_count=5`: Threshold để loại bỏ rare words
- `window=5` (default): Context window size
- `sg=0` (default): CBOW algorithm (sg=1 cho Skip-gram)

#### **Bước 4: PySpark Distributed Training (src/spark/lab4_task4_pyspark.py)**

Train Word2Vec trên large dataset sử dụng PySpark MLlib:

```python
from pyspark.sql import SparkSession
from pyspark.sql.functions import col, lower, regexp_replace, split
from pyspark.ml.feature import Word2Vec

# Khởi tạo Spark
spark = SparkSession.builder.master('local[*]').getOrCreate()

# Load và preprocess data
df = spark.read.json('data/c4-train.00000-of-01024-30K.json')
df = df.select(col('text'))
df = df.withColumn('clean', lower(col('text')))
df = df.withColumn('clean', regexp_replace(col('clean'), "[^a-z0-9\\s]", ' '))
df = df.withColumn('tokens', split(col('clean'), '\\s+'))

# Train Word2Vec
w2v = Word2Vec(vectorSize=100, minCount=5, inputCol='tokens', outputCol='result')
model = w2v.fit(df)

# Find similar words
model.findSynonyms('computer', 5).show()
```

**Ưu điểm PySpark:**
- Xử lý distributed trên large datasets
- Tự động parallelize training
- Tích hợp MLlib pipeline

**Lưu ý Windows:**
- Cần Java runtime
- Sử dụng `--no-save` flag để tránh lỗi winutils.exe

#### **Bước 6: Trực quan hóa Embeddings (test/lab4/visualize_embeddings.py)**

Sử dụng PCA để giảm chiều và visualize:

```python
from sklearn.decomposition import PCA
import matplotlib.pyplot as plt

# Lấy vectors của top 100 từ
vocab = list(model.wv.key_to_index.keys())[:100]
vectors = np.array([model.wv[word] for word in vocab])

# PCA 2D
pca_2d = PCA(n_components=2)
vectors_2d = pca_2d.fit_transform(vectors)

# PCA 3D
pca_3d = PCA(n_components=3)
vectors_3d = pca_3d.fit_transform(vectors)

# Plot 2D và 3D side-by-side
fig = plt.figure(figsize=(20, 8))
ax1 = fig.add_subplot(121)  # 2D plot
ax2 = fig.add_subplot(122, projection='3d')  # 3D plot
```

**Insights từ visualization:**
- Các từ semantically similar tập trung thành clusters
- Category grouping: Technology, Science, Business, Politics
- Explained variance: 2D (~28-38%), 3D (~38-49%)
