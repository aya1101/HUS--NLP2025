**Bước 3: Tạo Pipeline NLP**
```python
def create_pipeline():
    # Giai đoạn 1: Tách từ
    tokenizer = RegexTokenizer(
        inputCol="text", 
        outputCol="tokens",
        pattern="\\s+|[.,;!?()\"']"
    )
    
    # Giai đoạn 2: Loại bỏ từ dừng
    stop_words_remover = StopWordsRemover(
        inputCol="tokens", 
        outputCol="filtered_tokens"
    )
    
    # Giai đoạn 3: Tần số từ
    hashing_tf = HashingTF(
        inputCol="filtered_tokens", 
        outputCol="tf_features",
        numFeatures=NUM_FEATURES
    )
    
    # Giai đoạn 4: Tần số tài liệu nghịch đảo
    idf = IDF(
        inputCol="tf_features", 
        outputCol="features"
    )
    
    return Pipeline(stages=[tokenizer, stop_words_remover, hashing_tf, idf])
```

**Bước 4: Triển khai tìm kiếm Vector với độ tương tự Jaccard**
```python
def vector_search(spark, query_text, documents, k=5):
    # Biến đổi truy vấn sử dụng cùng pipeline
    query_vector = transform_query(query_text)
    
    # Tính toán độ tương tự Jaccard
    similarities = []
    for doc in documents:
        intersection = len(set(query_vector.indices) & set(doc.features.indices))
        union = len(set(query_vector.indices) | set(doc.features.indices))
        similarity = intersection / union if union > 0 else 0.0
        similarities.append(similarity)
    
    return sorted(similarities, reverse=True)[:k]
```

### 6.3 Chi tiết thuật toán
**Cấu hình HashingTF**:
- Hàm hash: MurmurHash3
- Không gian đặc trưng: 20,000 chiều
- Xử lý xung đột: Cộng dồn (nhiều từ ánh xạ đến cùng hash)

**Công thức trọng số IDF**:
```
IDF(t) = log((N + 1) / (DF(t) + 1)) + 1
```
Trong đó:
- N = tổng số tài liệu
- DF(t) = tần số tài liệu của từ t

**Công thức độ tương tự Jaccard**:
```
J(A,B) = |A ∩ B| / |A ∪ B|
```
Áp dụng cho các chỉ số khác không của vector thưa.

- **Vấn đề**: Kích thước từ vựng (39,585) > không gian đặc trưng (20,000)
- **Tác động**: Tỷ lệ xung đột hash ~49.5%
- **Giải pháp**: Cân bằng giữa bộ nhớ và độ chính xác, có thể tăng numFeatures

### 7.2 Hiệu suất tìm kiếm Vector
- **Thách thức**: Tìm kiếm qua bộ sưu tập tài liệu lớn
- **Giải pháp**: Giới hạn phạm vi tìm kiếm (100 tài liệu) để cân bằng tốc độ/độ chính xác

### 7.3 Môi trường Windows
- **Vấn đề**: Cảnh báo tương thích Hadoop/Parquet
- **Giải quyết**: Sử dụng đầu ra dựa trên văn bản thay vì Parquet

## 8. Công nghệ sử dụng

### 8.1 Công nghệ cốt lõi
- **PySpark 3.x**: Framework tính toán phân tán
- **MLlib**: Thư viện học máy
- **Spark SQL**: Xử lý dữ liệu có cấu trúc

### 8.2 Thành phần ML
- **RegexTokenizer**: Tokenization dựa trên mẫu
- **StopWordsRemover**: Từ dừng tiếng Anh tích hợp
- **HashingTF**: Tần số từ dựa trên hash (20,000 đặc trưng)
- **IDF**: Trọng số tần số tài liệu nghịch đảo

### 8.3 Tìm kiếm Vector
- **Độ tương tự Jaccard**: Độ tương tự dựa trên giao/hợp tập hợp
- **Phép toán Vector thưa**: Tính toán hiệu quả trên không gian đặc trưng lớn

## 9. Kết luận và hướng phát triển

### 9.1 Thành tựu đạt được
- ✅ Triển khai thành công pipeline NLP từ đầu đến cuối
- ✅ Tích hợp chức năng tìm kiếm vector
- ✅ Đạt được phát hiện độ tương tự cao (0.9538 cho khớp chính xác)
- ✅ Xử lý hiệu quả 2,000 tài liệu

### 9.2 Cải tiến trong tương lai
- Triển khai độ tương tự cosine cho khớp ngữ nghĩa tốt hơn
- Thêm tiền xử lý phức tạp hơn (lemmatization, nhận dạng thực thể có tên)
- Mở rộng cho bộ dữ liệu lớn hơn với tính toán phân tán
- Tích hợp với embedding dựa trên transformer hiện đại

- Ứng dụng tìm kiếm độ tương tự văn bản
